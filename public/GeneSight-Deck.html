The Problem

Scientific hypothesis generation doesn't scale.

📚

Literature overload

Over 33 million papers on PubMed. A researcher manually scanning relevant literature for a single hypothesis can spend weeks before forming a testable idea.

🔗

Fragmented databases

Gene metadata lives in NCBI. Protein data in UniProt. Disease relationships in literature. No single tool surfaces cross-database connections automatically.

🧪

Unverified leads

Most AI tools generate hypotheses with no grounding check. A hallucinated gene name or unsupported claim reaches the researcher as confidently as a real finding.

⏱️

Months per cycle

The literature → hypothesis → validation cycle takes months. Most promising gene-disease connections are never explored simply because the process doesn't scale.

The Pipeline

8 specialized async agents — each owns one job.

AGENT 01

Task Planner

Decomposes the user query into structured subtasks for downstream agents.

GPT-4o
AGENT 02

Literature Retrieval

Searches 33M+ PubMed papers via NCBI Entrez / Biopython.

PubMed · Entrez
AGENT 03

Biomedical Extractor

Runs NER to extract genes, diseases, proteins from retrieved papers.

spaCy NER
AGENT 04

Genomics DB Lookup

Enriches every extracted gene with metadata from NCBI Gene and UniProt.

NCBI Gene · UniProt
AGENT 05

Knowledge Graph

Builds a gene–disease–protein graph in Neo4j, enabling multi-hop relationship queries.

Neo4j AuraDB
AGENT 06

Hypothesis Generator

Reasons across the knowledge graph to generate ranked scientific hypotheses.

GPT-4o · LangGraph
AGENT 07

Evidence Validator

Checks each hypothesis gene against NCBI and retrieved papers. Flags anything ungrounded.

NCBI · faithfulness check
AGENT 08

Evaluator + Reporter

Scores overall analysis quality 0–100. Assembles the final structured report with D3 graph.

GPT-4o · D3.js

Production Reliability

A safety layer built for scientific claims.

Every layer of the pipeline has a failure mode addressed. This isn't a demo — it's designed to run reliably under real research conditions.

✓

Hallucination Guard

Every hypothesis gene is verified against the NCBI Gene database before reaching the report. Confabulated gene names are caught and flagged automatically.

✓

Faithfulness Check

Genes in hypotheses must appear in the retrieved papers. A claim with no literature grounding is marked low-confidence, not silently passed through.

✓

Prompt Injection Detection

Input guardrails check for injection attempts and enforce genomics topic scope before any query reaches the pipeline.

✓

Circuit Breakers

Auto-open on repeated failures to OpenAI, NCBI, or Neo4j — preventing cascade failures and surfacing dependency health clearly.

✓

Concurrency + Timeout

Max 3 simultaneous pipelines via semaphore. 5-minute hard timeout per run. IP rate limiting at 10 req/min protects upstream APIs.

✓

Per-Agent Tracing

Every agent run logs timing, token counts, and flags via /trace/{job_id}. Full audit trail for reproducibility.
